# Chess mover — Ø40 mm CAD concept

An offline-capable interactive WebGL viewer of an early robotic chessboard mover.

Open index.html or use the GitHub Pages website. Drag to rotate, scroll to zoom, inspect the magnet lift, or hide components.

This is iteration 5: a nominal 40 mm circular envelope, 25.2 mm installed plate spacing, 10 mm magnet travel, and a downward-facing camera. Later calculations exploring shorter lift travel are not incorporated into this CAD snapshot.

This is a packaging concept, not manufacture-ready hardware or a physics simulation. Several component envelopes, contacts, supports, shaft attachments and electronics are provisional.

The motor mesh derives from Pololu manufacturer N20 STEP geometry, with shortened output shafts. Manufacturer assets retain their original rights. The viewer uses plain JavaScript and WebGL; it requires no backend.
